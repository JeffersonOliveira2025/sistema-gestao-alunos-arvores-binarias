# Portal Acadêmico — Sistema de Gestão de Cadastro de Alunos

Sistema desktop para gestão acadêmica multi-campus, desenvolvido em Java com Spring Boot. Permite cadastro e consulta de alunos organizados por estrutura de dados em **Árvore Binária**, com interface gráfica construída em Java Swing.

## Funcionalidades
- Registro acadêmico de novo aluno, com seleção de campus
- Consulta de discentes em todos os campus
- Listagem de alunos por unidade (percurso in-order da árvore binária)

## Tecnologias
Java · Spring Boot · Swing · Maven · Estruturas de Dados (Árvore Binária)
